# ТЗ: DashCreator - Low-code платформа для создания бизнес-дашбордов

## 1. БИЗНЕС-КОНТЕКСТ И ЦЕЛЬ

### Проблема, которую решаем
Бизнес-пользователи (маркетологи, аналитики, менеджеры) тратят недели на ожидание дашбордов от разработчиков. Типичный сценарий:
- Отдел маркетинга хочет отслеживать новые метрики
- Запрос уходит в IT/разработку
- Разработчики (дорогой ресурс) делают простой дашборд 3-5 дней
- При необходимости изменений - цикл повторяется
- **Итог:** потеря скорости принятия решений, неэффективное использование разработчиков

### Решение
Создать low-code платформу, где бизнес-пользователь за 10-15 минут может:
1. Подключить источники данных
2. Перетащить нужные виджеты
3. Настроить их параметры
4. Получить готовый дашборд без привлечения разработчиков

### Целевая аудитория
- **Первичная:** Аналитики, маркетологи, product managers в e-commerce
- **Вторичная:** Стартапы, которым нужна аналитика без найма разработчиков

## 2. ФУНКЦИОНАЛЬНЫЕ ТРЕБОВАНИЯ

### 2.1. Основные модули

#### Модуль 1: Управление источниками данных (Data Sources)
- **Поддерживаемые источники:**
  1. REST API (с авторизацией: Bearer token, Basic auth, OAuth2)
  2. GraphQL endpoints
  3. CSV/Excel загрузка
  4. Google Analytics 4 API
  5. Google Sheets (как источник данных)

- **Функциональность:**
  - Тестирование подключения к источнику
  - Кеширование данных (настраиваемый TTL)
  - Преобразование данных (маппинг полей)
  - Планирование обновлений (каждые 5/15/60 минут)

#### Модуль 2: Библиотека виджетов (Widget Library)
**Базовые виджеты (MVP):**

1. **Time Series Chart**
   - Линейный, столбчатый, площадной график
   - Несколько осей Y
   - Накопительный режим
   - Сравнение периодов (YoY, MoM)

2. **Metric Card**
   - Большое число + заголовок + описание
   - Delta (изменение за период) с цветовой индикацией
   - Sparkline мини-график
   - Целевой индикатор (progress bar к цели)

3. **Data Table**
   - Сортировка по всем колонкам
   - Фильтрация (текст, диапазоны, категории)
   - Пагинация + виртуализация
   - Экспорт в CSV

4. **Geographic Map**
   - Хороплет (цветовые зоны по значению)
   - Bubble maps (размер круга = значение)
   - Интерактивные подсказки при наведении
   - Масштабирование/панорамирование

5. **Gauge / Progress Ring**
   - Круговой прогресс-бар
   - Целевые зоны (красная/желтая/зеленая)
   - Анимированное заполнение

#### Модуль 3: Конструктор дашбордов (Dashboard Builder)
- **Drag & Drop система:**
  - Перетаскивание виджетов из палитры
  - Привязка к сетке (grid snapping)
  - Изменение размеров (ресайз) с ограничениями
  - Порядок слоев (z-index)

- **Редактирование свойств:**
  - Панель свойств справа при выборе виджета
  - Живой превью изменений
  - Undo/Redo (до 50 действий)

- **Компоновка:**
  - Система колонок (12-колоночная сетка)
  - Контейнеры для группировки виджетов
  - Табы внутри дашборда

#### Модуль 4: Настройка данных и фильтров
- **Data Binding:**
  - Привязка виджета к источнику данных
  - Выбор полей для осей X/Y
  - Агрегации (sum, average, count, distinct)

- **Фильтры:**
  - Глобальные фильтры дашборда
  - Фильтры уровня виджета
  - Зависимые фильтры (каскадные)
  - Периоды времени (relative: last 7d, last month, custom range)

#### Модуль 5: Шеринг и экспорт
- **Режимы доступа:**
  - Private (только автор)
  - Team (внутри организации)
  - Public (ссылка без авторизации)

- **Экспорт:**
  - PNG (снимок текущего состояния)
  - PDF (многостраничный, с настройкой layout)
  - JSON (структура дашборда для бэкапа)

Пример виджета TimeSeries:
typescript
class TimeSeriesWidget extends BaseWidget {
  async getData(params: WidgetParams) {
    const { dataSource, filters, dateRange } = params;
    
    // 1. Получение данных из источника
    const rawData = await dataSource.fetch(filters);
    
    // 2. Трансформация для графика
    return this.transformForChart(rawData, {
      xField: params.config.xAxisField,
      yFields: params.config.yAxisFields,
      aggregation: params.config.aggregation
    });
  }
  
  render(options) {
    return (
      <ResponsiveContainer width="100%" height="100%">
        <LineChart data={options.data}>
          <XAxis dataKey="date" />
          <YAxis />
          <Tooltip />
          {options.config.series.map(series => (
            <Line 
              key={series.id} 
              dataKey={series.field}
              stroke={series.color}
            />
          ))}
        </LineChart>
      </ResponsiveContainer>
    );
  }
}
