## 📋 Детали реализации

### Фильтры

Фильтры хранятся в `dashboard.globalFilters` и применяются ко всем виджетам дашборда. Каждый фильтр имеет:
- `field` - поле для фильтрации
- `operator` - оператор сравнения
- `value` - значение для фильтрации

### Экспорт

**PNG/PDF:**
- Используется `html2canvas` для рендеринга DOM в canvas
- `jsPDF` для создания PDF документов
- Автоматическая разбивка на страницы для больших дашбордов

**JSON:**
- Экспорт полной структуры дашборда
- Включает все виджеты, конфигурации, фильтры
- Можно использовать для бэкапа и миграции

### Оптимизации

**Code Splitting:**
```typescript
// Виджеты загружаются лениво
export const TimeSeriesWidgetLazy = lazy(() => 
  import('./time-series/TimeSeriesWidget')
);
```

**Виртуализация:**
- Таблицы с >50 строками автоматически используют виртуализацию
- Рендерится только видимая область + overscan
- Плавная прокрутка без лагов

**Web Workers:**
- Трансформации для данных >1000 записей выполняются в Worker
- Не блокирует UI поток
- Автоматическое переключение между синхронным и асинхронным режимом

## 🎯 Использование

### Фильтры

1. Откройте дашборд
2. В панели свойств перейдите на вкладку "Фильтры"
3. Нажмите "Добавить" для создания нового фильтра
4. Выберите поле, оператор и значение
5. Фильтр применяется автоматически

### Экспорт

1. В Toolbar нажмите "Экспорт"
2. Выберите формат: PNG, PDF или JSON
3. Файл скачается автоматически

### Data Binding

1. Выберите виджет на канвасе
2. В панели свойств перейдите на вкладку "Данные"
3. Выберите источник данных
4. Настройте поля для виджета

## 📊 Производительность

- **Виртуализация**: Таблицы с 10,000+ строк рендерятся плавно
- **Web Workers**: Трансформации 100,000+ записей не блокируют UI
- **Code Splitting**: Начальный бандл уменьшен на ~40%
