# Руководство по вкладу в проект

Спасибо за интерес к DashCreator! Мы рады вашему вкладу.

## Как внести вклад

1. Fork репозитория
2. Создайте ветку для вашей фичи (`git checkout -b feature/AmazingFeature`)
3. Внесите изменения
4. Закоммитьте (`git commit -m 'Add some AmazingFeature'`)
5. Запушьте в ветку (`git push origin feature/AmazingFeature`)
6. Откройте Pull Request

## Стандарты кода

### TypeScript
- Используйте strict mode
- Избегайте `any`, используйте конкретные типы
- Документируйте публичные API с JSDoc

### Стиль кода
- Запустите `npm run lint` перед коммитом
- Запустите `npm run format` для форматирования
- Следуйте существующему стилю кода

### Коммиты
- Используйте понятные сообщения коммитов
- Один коммит = одно логическое изменение

## Структура проекта

```
src/
├── core/           # Ядро - не трогать без необходимости
├── modules/        # Бизнес-модули
├── components/     # Переиспользуемые компоненты
├── lib/           # Утилиты
└── services/      # Сервисы
```

## Добавление нового виджета

1. Создайте папку в `src/modules/widgets/`
2. Создайте класс, наследующий `BaseWidget`
3. Реализуйте все обязательные методы
4. Зарегистрируйте в `src/modules/widgets/index.ts`
5. Добавьте тесты (если есть)

## Тестирование

Перед отправкой PR убедитесь, что:
- [ ] Код компилируется без ошибок
- [ ] Линтер не выдает ошибок
- [ ] Проект запускается локально
- [ ] Новые фичи работают

Создайте Issue для обсуждения больших изменений.
